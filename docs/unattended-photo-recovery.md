# 무인 사진 처리 오류 대응

적용 범위: 시나리오/SID 물품의 무인 대여 확인 및 반납. 공구 직접 신청·반납의 기존 사진/중복 처리 방식은 변경하지 않는다.

## 이용자 흐름

1. 사진을 찍은 뒤 **이 사진으로 대여 확인 / 반납 처리** 버튼을 누른다. 촬영만 하고 닫으면 처리되지 않는다.
2. 사진과 선택 물품·수량을 PC의 IndexedDB 임시 보관함에 저장한다. 비밀번호·로그인 표는 저장하지 않는다.
3. 서버에서 사진 저장과 장부 반영을 완료했다는 영수증을 확인한 뒤에만 완료 화면을 표시한다.
4. 연결 실패·응답 유실은 같은 요청 번호로 한 차례 자동 재시도한다. 서버가 이미 끝냈다면 영수증만 회수하며 재고를 다시 변경하지 않는다.
5. 계속 실패하면 촬영본과 선택을 유지하고 **같은 촬영본으로 다시 확인**을 누를 수 있다. 연결 복귀 시에도 재확인한다.
6. 새로고침·로그아웃 후에는 같은 PC에서 본인 사번으로 로그인하면 미완료 촬영을 복구한다. 다른 사람의 사진은 표시하지 않는다.
7. 사진을 읽지 못하면 선택 물품은 유지한 채 다시 촬영할 수 있다. 관리자 검토가 종료된 건은 서버에서 그 상태를 확인한 뒤 임시 보관을 종료할 수 있다. 임시 보관 종료 자체는 대여/반납 처리가 아니다.

## 서버와 페널티

- `unattended_operations`에 사진 검증 여부·선택 스냅샷·수신 시각·파일 경로·오류·검토/완료 상태를 기록한다. 완료 상태는 실제 장부와 같은 트랜잭션에서만 저장한다.
- 동일 요청의 소유자·물품·수량·업무 변경을 거부한다. 동일 요청 동시 처리와 서로 다른 요청의 동일 물품 동시 처리도 재검증한다.
- 사진을 검증하고 수신한 뒤 파일 저장/장부 반영이 실패하면 일반 완료 사진과 구분한 관리자 확인 대상으로 남긴다.
- **원래 기한 전에 서버에 검증된 사진이 도착한 기술 오류**만 해당 물품의 자동 취소·자동 페널티 판정을 보류한다. 미수령 전체 수량에 대한 증빙이 필요하며 일부 수량의 실패가 선택하지 않은 나머지 수량까지 면제하지 않는다. 정상 처리 중인 부분 수량은 최대 2분간 충돌을 막는다.
- 예약도 원래 예정 시각 +20분을 기준으로 같은 기술 오류 보류를 적용한다. 예약 시각이나 일반 4시간/24시간 규칙 자체를 연장하는 변경은 아니다.
- 잘못된 입력·타인 요청·종류 미정·이미 처리된 물품 등 사용자/상태 검증 거절은 기술 오류 면제로 사용하지 않는다.
- 이미 부과된 페널티나 과거 S15477 기록은 자동 변경하지 않는다.

## 관리자 조치

관리자 **대여 및 반납** 상단에 ‘무인 촬영 처리 확인 필요’가 나타난다. 정상 처리 중인 요청은 표시하지 않고 실패 또는 2분 넘게 멈춘 요청만 표시한다.

1. 사번·물품·수량·시각·오류와 도착한 사진을 확인한다.
2. 실물 및 기존 대여 기록을 확인하고, 필요한 대여 확인/반납을 기존 화면에서 처리한다.
3. 조치 내용을 적고 **조치 후 검토 종료**를 누른다. 이 버튼은 재고/대여를 임의 처리하지 않는다. 남아 있는 미처리 건에는 원래 기한에 따른 자동 판정이 재개되므로 처리 상태를 먼저 확인한다.

검토 대기 중인 오류 증빙은 7일 자동 정리에서 제외한다. 완료 또는 검토 종료된 증빙 파일은 기존 보관 기간(기본 7일) 뒤 정리한다. 완료 영수증·요청 번호는 남겨 중복 처리를 방지한다.

## 한계와 주의

- 사진/요청이 서버에 전혀 도착하지 않으면 서버가 기술 오류를 판별할 수 없다. PC 임시 보관과 재전송으로 복구하되, 기한이 이미 지났다면 관리자의 확인이 필요하다. 클라이언트가 적은 촬영 시각만으로 과거 페널티를 자동 면제하지 않는다.
- 브라우저 데이터 삭제·PC 디스크 장애·저장 공간 부족은 IndexedDB 복구를 막을 수 있다. 임시 저장 실패 시 현재 창 메모리에도 보존하고 경고하며, 가능하면 완료 전 창을 닫지 않는다. 임시 저장 실패 촬영은 같은 페이지 내 재로그인에서 메모리 복구할 수 있지만 브라우저 자체가 종료되면 잃을 수 있다.
- 사진 촬영/전송 및 미완료 촬영이 있는 동안 버전 갱신 보호를 적용한다. 완료 전 새로고침·창 닫기에는 브라우저 경고를 표시한다.
