# Shoot Planner 계획 이름·표시·임시 컬렉션 보관 (2026-10-19)

새 계획 이름은 촬영 날짜의 `YYYY-MM-DD 촬영 계획`이다. 날짜 변경 시 자동 이름을 따라 바꾸며,
직접 수정한 이름은 유지한다. 초안에 자동/수정 여부를 저장하고 기존 사용자 초안의 이름도 보존한다.
대여 신청 번호는 완료 안내·대여 상태·취소 안내·계획 상세에서 숨긴다. 내부 WMS 식별에는 사용한다.
좌석은 초기 선택창과 층 변경 후 목록 모두 같은 숫자 정렬을 적용한다.

엑셀·붙여넣기 컬렉션은 최초 업로드 후 14일이 지나면 기존 수동 삭제의 `deleted=1`로 전환한다.
물리적인 행·영상 파일을 지우지 않는다. 앱 시작, 매시간, 목록/상세 조회에서 정리한다.
추가 업로드·물품 갱신은 최초 업로드 시각을 변경하지 않는다. 만료된 원본으로 새 계획을 만들 수 없으며,
이미 배포된 계획은 별도 스냅샷이므로 계속 동작한다. 자동 삭제는 이력에 기록한다.
Data Operator 원본, WMS 재고·대여, 배포 계획·진행 기록은 이 정책의 대상이 아니다.

Shoot Planner `server/uploadRetention.cjs`, `server/server.cjs`, `public/app.js`에 구현했다.
테스트 39개와 합성 데이터의 브라우저 흐름 검증을 통과했다. 배포는 코드와 운영 SQLite의 온라인 백업 후 적용한다.
