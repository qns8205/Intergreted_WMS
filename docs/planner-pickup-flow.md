# Shoot Planner 수령 확인과 좌석 선택 (2026-10-19)

- 내 계획 상단의 층·좌석 입력을 없앴다. 지금 대여 신청 또는 예약 대여 신청을 누른 뒤 물품 목록과 함께 층·좌석을 선택한다. 이전 좌석은 기본값으로 표시하며, 취소하거나 선택이 유효하지 않으면 저장·신청하지 않는다.
- 신청 직후에는 완료 안내와 WMS 대여 확인 대기를 표시한다. WMS 신청 전체의 상태가 `confirmed` 또는 `pickedUp`이 된 뒤에 수령 확인창을 자동으로 한 번 표시한다. 일부 물품만 확인된 신청은 전체 상태가 `requested`이므로 대기한다.
- 사용자가 '아직'을 선택하면 자동 확인창을 반복하지 않고 수령 확인 버튼을 남긴다. 수령 버튼을 누르거나 최종 확인할 때 WMS 상태를 다시 조회한다. 그 사이 취소되었거나 다른 신청으로 바뀌었으면 진행하지 않는다.
- 기존 기록을 다시 여는 경우 `returned` 상태의 수령 체크는 유지한다. 양도받은 보유 물품만 사용하는 루틴과 새로 빌릴 물품이 없는 루틴의 기존 흐름은 지원한다.
- 서버의 `/api/my-plans/:id/progress`도 WMS 상태를 검사하므로 예전 화면이나 직접 요청으로 확인 전 수령 체크를 저장할 수 없다. 이 검증은 한 요청의 모든 진행 기록을 쓰기 전에 실행한다.
- 상태는 기존 30초 갱신 또는 '대여 확인 상태 새로고침'으로 확인한다. Data Operator나 QA Tool의 별도 쓰기·동기화를 추가하지 않는다.
