# 대여 방식 운영 인수인계 (2026-10-19)

물품 관리자가 웹앱에서 대여 방식(일반 대여 · 사유 대여 · 장기대여)을 다루는 방법을 정리한 문서입니다.

## 1. 왜 바뀌었나

오브젝트가 한 사람에게 오래 머물러 다른 사람의 시나리오 제작에 차질이 생기는 일이 반복되었습니다. 그래서 대여할 때 대여 방식을 고르게 하고, 일반 대여에는 반납 기한을 두었습니다. 관리자의 역할은 **물품이 계속 순환하도록 기한과 사유를 관리하는 것**입니다.

## 2. 세 가지 대여 방식

| 방식 | 신청할 때 입력 | 반납 기한 | 기한을 넘기면 |
|---|---|---|---|
| 일반 대여 | 없음 | 수령 확인 후 4시간 | 대여 가능 종류 5종이 48시간 동안 차감 (신청당 한 번) |
| 사유 대여 | 대여 사유 | 없음 | 자동 차감 없음 |
| 장기대여 | 대여 사유 + 반납 예정일 | 선택한 날짜 | 자동 차감 없음 |

- 4시간은 **신청 시각이 아니라 대여 확인(수령) 시각부터** 셉니다. 대여 확인을 늦게 하면 사용자 기한도 늦게 시작합니다.
- **점심시간(12:00~13:00)은 4시간에서 빠집니다.** 10:00 수령 → 15:00까지, 12:30 수령 → 13:00부터 세어 17:00까지, 08:00 수령 → 12:00까지. 화면에 보이는 반납 기한은 이미 점심시간을 뺀 시각입니다.
- 대여 방식은 **신청 단위**입니다. 한 신청 안의 물품은 모두 같은 방식이고, 방식을 바꾸면 그 신청 전체가 바뀝니다.
- Shoot Planner로 신청한 대여는 시간 제한과 차감이 없습니다. 루틴이 끝나면 반납하는 기존 방식 그대로입니다.
- 새 규칙 이전에 빌려 간 예전 대여에는 방식이 없고, 4시간 규칙도 적용되지 않습니다.

## 3. 어디서 보나 — 대여 & 반납 관리 › 대여 및 반납

대여 확인·반납 목록의 각 물품 줄에서 다음을 볼 수 있습니다.

- **대여 방식 칩:** 예) `일반 대여 · 2026-10-19 20:33:14까지 반납`, `사유 대여 · 4시간 제한 면제`, `장기대여 · 2026-10-25까지 반납`
- **사유 줄:** 대여 사유, 관리자 변경 사유, 한도 제외 사유가 있으면 모두 아래 줄에 나옵니다.
- **오른쪽 버튼:** 방식에 따라 `일반 대여로 변경` 또는 `사유 대여로 변경`이 나옵니다.

사용자는 자기 화면의 **내 대여 목록**에서 같은 방식·사유·기한을 확인합니다.

## 4. 대여 방식 바꾸기

### 사유 대여 · 장기대여 → 일반 대여
사유가 적절하지 않을 때 씁니다. (예: 단순 보관, 사유가 너무 막연함)

1. 해당 물품 줄의 **`일반 대여로 변경`**을 누릅니다.
2. **변경 사유**(왜 사유를 인정하지 않는지)를 입력하고 **`일반 대여로 변경`**을 누릅니다.
3. 이미 수령한 물품은 **지금부터 4시간**, 아직 수령하지 않은 물품은 **수령 확인부터 4시간** 안에 반납해야 합니다.
4. 변경 사유는 사용자의 내 대여 목록에 그대로 보입니다. 사용자가 읽는다고 생각하고 써주세요.

### 일반 대여 → 사유 대여
일반 대여로 신청했지만 오래 써야 할 정당한 이유가 있을 때 씁니다. 사용자가 직접 바꿀 수는 없으므로 관리자에게 요청합니다.

1. 해당 물품 줄의 **`사유 대여로 변경`**을 누릅니다.
2. **대여 사유**를 입력하고 **`사유 대여로 변경`**을 누릅니다. 한도 제외 물품이면 제외 사유가 미리 채워져 있습니다.
3. 4시간 제한이 사라집니다.
4. **이미 부과된 차감은 자동으로 풀리지 않습니다.** 풀어줘야 하면 **설정 › 대여/반납 설정**의 개인별 페널티에서 따로 수정해주세요.

> 같은 신청을 여러 번 바꿔도 됩니다 (일반 → 사유 → 일반 …).

## 5. 양도

양도하면 원래 대여 방식이 받는 사람에게 이렇게 넘어갑니다.

| 원래 방식 | 받는 사람에게 |
|---|---|
| 사유 대여 | 같은 사유의 사유 대여 |
| 장기대여 | 같은 사유·같은 반납 예정일의 장기대여 |
| 일반 대여 | 일반 대여. **4시간 기한이 양도 시점부터 새로 시작**됩니다 |

- **사용자가 직접 양도하는 경우 (양도하기 화면):** 위 표대로 넘어갑니다. 원래 물품의 한도 제외 표시도 함께 넘어갑니다.
- **관리자가 대신 양도하는 경우 (대여 및 반납 화면에서 물품을 담고 받는 사람 지정 → `양도하기`):**
  - 위 표대로 넘어갑니다.
  - 반납 예정일이 이미 지난 장기대여는 날짜를 새로 정할 수 없어서 같은 사유의 **사유 대여**로 넘어갑니다.
  - 한도 제외 표시는 넘어가지 않으니, 필요하면 받는 사람 줄에서 다시 지정해주세요.
- **대여 방식이 없는 예전 대여를 양도할 때:**
  - 양도 화면(사용자 양도하기 화면, 관리자 양도 칸 모두)에 대여 방식 선택이 나옵니다.
  - 고른 방식 하나가 그 물품 모두에 한 번에 적용됩니다.
  - 방식을 고르지 않으면 양도가 진행되지 않습니다. 사유 대여는 사유를, 장기대여는 사유와 예정일을 입력해야 합니다.
  - 방식이 이미 있는 물품은 원래 방식이 그대로 넘어갑니다.
- 방식이 다른 물품을 한 번에 양도하면 받는 사람 쪽에서 방식별로 신청이 나뉩니다.
- 양도 내역은 **대여 & 반납 관리 › 양도 알림**에서 확인합니다.

## 6. 한도 제외와의 관계

- **한도 제외:** "이 물품은 대여 가능 종류 수에서 빼준다"는 표시입니다. 물품 줄의 `한도 제외` 버튼으로 켜고 끕니다.
- **사유 대여:** "4시간 반납 기한을 면제한다"는 뜻입니다.
- 둘은 별개입니다. 오래 가지고 있어야 하는 물품이면 보통 **둘 다** 필요합니다.
- 2026-10-19에 그때 한도 제외 중이던 물품을, 제외 사유를 대여 사유로 하는 사유 대여로 일괄 전환했습니다. (12개 신청, 49개 물품)
- 단, **최지훈 님의 Vehicle Engine Hose, Vehicle Engine 2개**는 신청 번호가 없는 아주 오래된 기록이라 전환되지 않았습니다. 한도 제외로만 남아 있으니, 반납 후 다시 대여시켜 정리할지 그대로 둘지 정해주세요.

## 7. 자주 받을 질문

- **"4시간이 지났는데 차감됐어요."** 대여 방식 칩에서 일반 대여인지, 기한이 언제였는지 확인합니다. 정당한 사유가 있었다면 사유 대여로 바꾸고, 페널티는 설정 › 대여/반납 설정에서 따로 수정합니다.
- **"양도받았는데 바로 4시간이 시작됐어요."** 일반 대여를 양도받으면 양도 시점부터 4시간입니다. 오래 써야 하면 사유 대여로 바꿔줍니다.
- **"양도받았는데 사유가 그대로예요."** 정상입니다. 사유 대여·장기대여는 원래 사유가 그대로 넘어옵니다. 사유가 맞지 않으면 일반 대여로 바꾸거나 새로 신청하게 합니다.
- **"내 기한이 어디 나와요?"** 사용자 화면의 내 대여 목록에 나옵니다.
