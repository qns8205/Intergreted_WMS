# Shoot Planner 반납 추천 표시

반납 처리에서 계획에 연결된 실제 수령 대여만 대상으로 추천한다. 같은 계획·사번의
이전 루틴 보유분과 여분을 합친 뒤 다음 루틴의 keep 수량을 남기고 나머지를 표시한다.
부분 반납 후에는 실제 남은 보유 수량으로 다시 계산한다. 종류 지정 keep을 먼저 확보하고
물품 단위 keep은 남은 종류에서 확보한다. 미수령 예약은 현재 루틴을 앞당기지 않는다.
새 대여가 없는 루틴은 Collector의 수령·촬영 진행 기록으로 연결한다.

추천 대상 대여자가 목록 위로 이동하고 초록색 배지가 표시된다. 대여자를 펼치면
`계획 반납 추천` 묶음이 신청 시각·한도 제외 묶음보다 먼저 나온다. 추천 수량이 보유 수량보다
작으면 둘 다 표시한다. 장바구니 담기·확인·반납·재고 처리는 자동으로 실행하지 않는다.
대여 확인 화면과 COS 물품의 기존 정렬은 유지한다.

플래너의 서버 키 인증을 그대로 사용하며 추천은 관리자 getUnreturnedItems에만 포함한다.
브라우저에는 서버 키를 보내지 않는다. 플래너 장애 시 추천 없이 실제 대여 목록을 반환한다.
보관 재고·대여·계획 DB 변경은 없으며 코드 배포 후 두 서비스를 재시작한다.
