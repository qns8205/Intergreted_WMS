# 대여 방식과 반납 기한

일반 대여는 사유 없이 신청하며 실제 수령 확인 후 4시간 이내에 반납한다. 신청 후 수령까지 기다린 시간은 포함하지 않는다. 한국 시각 12:00~13:00 점심시간은 4시간에 포함하지 않는다(`shared/rentalTerms.js`의 `addRentalTimeMs`). 초과 시 신청당 한 번 대여 가능 종류 5종을 48시간 차감한다. 여러 물품·부분 수령·부분 반납이 같은 신청에 있어도 중복 차감하지 않는다. 서버는 시작 후 및 1분 간격으로 확인하므로 차감 반영은 최대 약 1분 뒤다. 점검 사이에 늦게 반납한 건도 확인한다.

사유 대여는 사유가 필수이고 4시간 제한에서 면제된다. 장기대여는 사유와 한국 날짜 기준 반납 예정일이 필수이고, 관리자 대여 확인·반납 화면 및 본인 대여 목록에 예정일과 사유를 표시한다. 장기대여 예정일 초과에 별도 자동 제재를 추가하지 않는다.

관리자는 대여 확인·반납 화면에서 사유 대여나 장기대여를 일반 대여로 변경할 수 있다. 변경 사유는 필수이며 신청 전체에 적용된다. 기존 사유·예정일, 변경 사유·관리자·시각은 검토 이력에 보존한다. 이미 수령한 물품은 변경 시점부터 4시간, 미수령 물품은 실제 수령 확인부터 4시간을 적용한다. 같은 변경을 재전송해도 기한이 연장되지 않는다. 종료된 신청과 Planner 대여는 이 방식으로 변경할 수 없다. 해당 신청 사유로 자동 부여한 Request 종류 한도 제외는 함께 해제하며 별도 사유로 지정한 한도 제외는 유지한다. 본인 대여 목록에도 관리자 변경 사유와 새로운 반납 기한을 표시한다.

일반 신청과 예약 신청, 관리자 대리 신청에서 같은 세 가지 선택지를 사용한다. 예약의 4시간은 예약 등록이나 자동 전환 시각이 아닌 실제 수령 확인부터 계산한다. Request 물품의 기존 종류 한도 제외는 사유·장기대여 선택 시 유지하며, 함께 담은 일반 물품의 종류 한도 제외와는 별개다.

Shoot Planner의 인증된 연동 경로에서 생성된 즉시 대여·예약 자동 전환은 `planner` 방식으로 저장하고 시간 제한과 새 미반납 차감에서 제외한다. 일반 대여 API의 payload로 Planner 방식을 위조할 수 없다. 루틴 종료 후 반납하는 기존 Planner 흐름을 따른다. 과거 Planner 장부도 무인 모드 24시간 미반납 페널티에서 제외한다.

새 방식은 `rental_requests.rental_mode/rental_reason/rental_due_date`에 저장하며, 기존 대여는 NULL로 남겨 새 규칙을 소급하지 않는다. 분할된 물품 행은 신청 번호로 같은 사유·예정일을 조회한다. `rental_overdue_events.request_no` 기본 키로 신청당 중복 부과를 방지한다.

새 자동 차감은 `penalties.deduction_types=5`로 저장한다. 유효한 차감을 합산해 기존 대여 한도에서 빼고 최소 0종으로 제한한다. 차감마다 정확히 48시간 뒤 만료하므로 서로 다른 신청이나 기존 관리자 페널티의 만료 시간을 연장하지 않는다. 자동 차감의 원인 신청과 물품은 기존 페널티 상세 화면에서도 확인할 수 있다. 새 정책 신청에는 기존 무인 모드 24시간 미반납 페널티를 중복 적용하지 않는다.
