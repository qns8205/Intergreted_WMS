# 무인 공구 AI 검색 (시험 적용)

공구 신청 안내에는 **AI 검색은 선택사항이며 물품 이름만 직접 입력해도 된다**는 안내를 강조합니다. 이름·수량 입력과 사진 촬영만으로 기존 신청을 완료할 수 있습니다.

공구 이름 오른쪽의 **AI 검색**을 눌렀을 때만 검색합니다. 이름·키워드·한영 유사어와 EmbeddingGemma의 유사도를 함께 사용하며 후보 5개를 사진·이름·재고와 함께 표시합니다. 유사도는 정답 확률이 아닙니다. 후보 선택만으로 출고하지 않으며, 기존 사진 촬영과 신청 완료 절차가 유지됩니다.

알려진 공구 종류·유사어는 해당 종류의 이름/키워드에 맞는 후보로 범위를 제한한 뒤 AI로 정렬합니다. 예를 들어 실제 줄자가 없을 때 영어 `tape measure` 때문에 접착 테이프가 추천되는 것을 막습니다. 알려지지 않은 이름·설명은 AI 유사도로도 후보를 찾습니다. 오추천 가능성 때문에 자동 선택하지 않습니다.

선택한 공구의 ID와 이름이 신청 시점에도 일치하는지 검증합니다. 삭제·이름 변경·재고 부족은 관리자 확인 대기로 기록하고 다른 재고를 추측해서 차감하지 않습니다. 이름을 수정하거나 선택 해제를 누르면 기존 직접 입력 방식으로 돌아갑니다.

- 모델: EmbeddingGemma 300M Q8_0, llama.cpp b11333. 기존 테스트와 같은 검증된 파일 재사용.
- `wms-tool-ai.service`: 기존 WMS와 별도 프로세스. 127.0.0.1:18087에만 연결, CPUQuota=100%, MemoryMax=2GiB, swap=0, Nice=10. 부팅 시 자동 시작.
- `server/data/tool-ai-config.json`의 `enabled: true` 또는 환경 변수 `WMS_TOOL_AI_URL`로 활성화. 환경 변수도 HTTP loopback 주소만 허용.
- `server/data/tool-search-vectors.json`: 이름·키워드·분류가 그대로면 벡터 재사용. 시작 5초 뒤 및 5분 간격으로 변경된 항목만 비동기 갱신. 초기 생성 중에도 이름 검색 가능.
- 모델 호출 2.5초 제한, 동시 추론 1개. 모델 사용 중·오류·미준비 시 이름·유사어 검색으로 대체. 프론트 6초 제한 및 닫기/화면 변경 시 요청 취소, 기존 입력과 사진 유지.
- 사번·무인 모드 검증, 사번/IP별 10초에 5회 제한. 공개 화면에 보관 위치는 노출하지 않음. 검색 API는 재고·대여 장부를 변경하지 않음.

## 운영 확인

`systemctl status wms-tool-ai`, `journalctl -u wms-tool-ai`, `curl http://127.0.0.1:18087/health`.

AI 중지: `sudo systemctl stop wms-tool-ai`. WMS 신청·반납은 계속 동작하고 검색은 이름·유사어로 대체됩니다. 완전 비활성화는 설정의 `enabled`를 false로 바꾸고 WMS 재시작. 재고 DB 또는 다른 서비스를 수정할 필요 없음.

처음 설치할 때 `deploy/install-tool-ai.py`는 기존 벤치마크 산출물의 모델 SHA-256을 검증하고 `ai/`에 복사한 뒤 지정된 서비스만 등록합니다. 이 PC의 설치 경로와 계정에 맞춰진 스크립트입니다.

## 시나리오 물품 검색

일반 모드·무인 모드 모두 지원합니다. 기존 시나리오 물품 검색창 오른쪽의 AI 검색은 클릭할 때만 실행됩니다. 등록된 사번 또는 기존 관리자 세션을 확인하는 GET `/api/scenario-search`이며, 사번/IP별 10초 5회 제한이 있습니다.

- 활성 물품의 공개 이름·카테고리·서브카테고리·종류 이름만 인덱싱합니다. 보관 위치·관리용 SM 속성·구매 링크·메모는 검색 문서에 포함하지 않습니다.
- 물품 ID는 앞자리 0을 유지하는 문자열입니다. API는 추천 ID 목록만 반환하고 사진·재고·위치 표시 정책은 기존 카드가 처리합니다. 보관 물품 제외, Request 제외/카테고리/서브 필터를 후보 수 제한 전에 적용합니다.
- AI 결과는 관련도순 최대 20건. 기존 담기·주의 안내·종류 선택 모달 유지. 추천만으로 장바구니/재고를 변경하지 않습니다.
- AI 판단은 이름의 의미·카테고리·종류를 함께 사용합니다. 이름 완전 일치 및 이름의 여러 단어 일치(순서 무관)를 우선하고, 이름 유사어도 반영합니다. 카테고리만 맞는 항목의 문자 일치 점수는 보조 수준으로 제한합니다. 공구 검색에도 이름 단어 일치를 반영합니다. 기존 이름 포함 벡터를 재사용하며 추가 모델 호출은 없습니다.
- 검색어/필터 변경은 AI 결과를 해제하고 기존 검색으로 돌아갑니다. '일반 검색으로' 버튼도 제공하며 장바구니는 지우지 않습니다. 화면 이동은 진행 중 요청만 취소하고 완료한 결과·장바구니는 유지합니다.
- 기본 검색은 이름·ID·보관 위치의 문자 일치만 사용하며 일치도가 높은 항목을 먼저 표시합니다(동점은 선택된 정렬 사용). 분류·Request 대상·소유자·한영 유사어는 일반 검색의 검색 대상에서 제외. 카테고리는 기존 필터로 선택합니다. 무인 모드의 위치 검색 제외는 유지합니다.
- 명시적인 normal/ai 모드 구분. 검색어 입력 이벤트에서 동기적으로 AI 요청 취소·일반 모드 복귀, Enter도 일반 검색. 추천 표시에는 AI 모드 및 현재 검색어 일치 검증을 추가하여 늦게 온 이전 결과를 차단합니다. AI API 호출은 AI 검색 버튼 핸들러에만 있습니다.
- 모델은 공구 검색과 같은 `wms-tool-ai` 한 개를 공유합니다. 별도 모델 프로세스 추가 없음. 프로세스 내 공구/시나리오 추론은 서로 큐를 쌓지 않고, 이미 모델 사용 중이면 이름·유사어 검색으로 대체합니다.
- `server/data/scenario-search-vectors.json` 캐시, 변경된 이름/분류/종류만 비동기 재생성. 전체 카탈로그를 캐시하므로 필터 검색이 다른 분류의 벡터를 삭제하지 않습니다.
