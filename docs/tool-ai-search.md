# AI 검색 제거 (2026-10-14)

리소스 절약을 위해 시나리오 및 공구의 Gemma AI 검색을 제거했다.

- AI 검색 버튼·추천 결과·API와 모델 연결·벡터 인덱스 자동 갱신을 제거.
- 시나리오 이름·ID·위치 일반 검색 및 기존 필터/정렬은 유지.
- 무인 공구 이름 입력의 일반 후보 목록(이름·키워드·정해진 한영 유사어)은 유지. 모델 호출이나 벡터 캐시 없이 처리.
- 직접 이름 입력·수량·사진 촬영과 공구 신청/반납/관리자 재고 연결 과정은 유지.
- 운영 전용 wms-tool-ai 서비스 중지 및 자동 시작 해제. 모델·캐시·설정은 비활성 백업으로 이동하여 복구 가능하게 보관.
- 재고·대여·예약 장부 변경 없음.

과거 AI 검색 설명은 Git 이력에서 확인할 수 있다. 모델 재설치 스크립트와 벤치마크도 현행 코드에서는 제거했다.
